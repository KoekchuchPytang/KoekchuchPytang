## 🏰 Projetos

| Projeto | O que é | Stack |
|---|---|---|
| 🛡️ **[Home SOC Lab](https://github.com/KoekchuchPytang/home-soc-lab)** | Laboratório de SOC/Blue Team em 3 VMs isoladas (servidor Wazuh + endpoints Windows e Linux). Detecção validada de brute-force, malware (EICAR) e FIM, dashboard customizado e alertas por e-mail, com referência ao MITRE ATT&CK. | `Wazuh` `Sysmon` `auditd` `VirtualBox` |
| 🔁 **[Pipeline CI/CD com GitHub Actions](https://github.com/KoekchuchPytang/Desafio-Pipeline-CI-CD-Completo-com-GitHub-Actions)** | API FastAPI com pipeline completa seguindo GitFlow: testes com pytest, SAST com Semgrep, build e publicação de imagem no Docker Hub, com branch protection. | `GitHub Actions` `Docker` `Semgrep` `FastAPI` |
| ☸️ **[Desafio Kubernetes: PostgREST + PostgreSQL](https://github.com/KoekchuchPytang/k8s-postgrest-postgres-challenge)** | API integrada a banco de dados em cluster local, com PVC, ConfigMaps, Secrets, probes, escala manual e HPA. Persistência e autoscaling comprovados com evidências. | `Kubernetes` `minikube` `PostgreSQL` `PostgREST` |
| 🔗 **[Encurtador Foldway](https://github.com/JosephLMedeiros/Encurtador-Foldway)** | Encurtador de links cloud-native feito em equipe num hackathon CloudOps: Frontend → API → Postgres no Kubernetes, entregue por GitHub Actions + ArgoCD (GitOps). **Minha parte: observabilidade** (Grafana, Prometheus e afins). | `Kubernetes` `ArgoCD` `OpenTelemetry` `Grafana` `Prometheus` |
